# SQL Practice: Rideshare Database

Practice SQL queries (PostgreSQL) on a small rideshare-style database with riders, cars and trips. All data is made up.

## Files
- `schema.sql` - creates the `riders`, `riders2`, `cars` and `trips` tables
- `seed.sql` - inserts sample rows
- `queries.sql` - 9 queries

## Concepts practiced
`CROSS JOIN`, `LEFT JOIN`, `INNER JOIN`, `UNION ALL`, aggregates (`AVG`, `COUNT`), `WHERE`, `ORDER BY`, `LIMIT`

## How to run
1. Create a database (for example `rideshare_db`) in Postbird or `psql`.
2. Run `schema.sql`, then `seed.sql` (once).
3. Run the queries in `queries.sql` one at a time.

## Tools
PostgreSQL, Postbird
